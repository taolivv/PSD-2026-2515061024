# Sistem Leaderboard Buku Terlaris Menggunakan Binary Search Tree (BST)

## Deskripsi Singkat
Program ini merupakan simulasi sistem leaderboard buku terlaris yang menggunakan struktur data Binary Search Tree (BST). Pengguna dapat menambahkan data buku beserta jumlah penjualannya, melihat ranking buku berdasarkan jumlah terjual, menghapus buku dari leaderboard, menampilkan buku dengan penjualan tertinggi (terlaris), serta melihat total keseluruhan penjualan buku yang tercatat.
Program ini mengimplementasikan struktur data Binary Search Tree karena data buku perlu diurutkan secara otomatis berdasarkan jumlah terjual. BST memungkinkan pencarian, penyisipan, dan penghapusan dilakukan secara efisien dengan menjaga urutan data. Traversal in-order digunakan untuk menghasilkan ranking dari terkecil hingga terbesar, sementara fungsi terlaris memanfaatkan penelusuran ke node paling kanan untuk mendapatkan nilai maksimum secara langsung tanpa harus menelusuri seluruh data.

Program dimulai dengan menampilkan menu utama yang terdiri dari lima pilihan: Tambah buku, Lihat ranking, Hapus buku, Info terlaris & total terjual, dan Keluar. Pengguna dapat memilih menu secara berulang hingga memilih opsi 5 untuk mengakhiri program.
Jika pengguna memilih menu 1, program meminta input judul buku dan jumlah terjual. Setelah data dimasukkan, program menyisipkan buku ke dalam BST secara otomatis pada posisi yang sesuai berdasarkan jumlah terjual, kemudian mencetak konfirmasi bahwa buku berhasil ditambahkan.
